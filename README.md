# 🎙️ Voice Assistant with Python and Local AI

A beginner-friendly voice assistant built with Python that can listen to spoken commands, convert speech to text, generate AI responses using a locally running Llama 3.2 model, and speak the response back to the user.

## ✨ Features

- 🎤 Voice input using microphone
- 📝 Speech-to-text conversion
- 🧠 Local AI responses using Ollama and Llama 3.2
- 🔊 Text-to-speech using Windows Speech Synthesis
- 💬 Conversation memory during the current session
- 🚪 Voice commands to exit the assistant
- 💰 No paid OpenAI API required

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- SoundDevice
- SciPy
- Ollama
- Llama 3.2
- Windows PowerShell Speech Synthesis
